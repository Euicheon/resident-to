# 전공의·인턴 TO 대시보드

`*.csv` (전공의/인턴 정원(TO) 자료, 2022 후반기 ~ 2027 전반기)를 조회·시각화하는 웹 도구입니다.
서버·인터넷 없이 동작하며, **`web/index.html` 을 더블클릭**하면 바로 열립니다.

## 주요 기능
- **필터**: 구분(레지던트/인턴), 모집 시기(2022 후반기~2027 전반기·전체 합산), 지역(수도권/비수도권 프리셋), **과목(필수의료/인기과 프리셋)**, **병원 규모**, TO 0 제외 / 별도정원만 / 2027 신규만, 병원·과목·비고 검색(단축키 `/`)
- **차트 대시보드**
  - 시기별 TO 추이 (2022~2027) — 지역 또는 과목을 1~6개 선택하면 다중 추이선으로 자동 분리
  - 지역별 TO (수도권/비수도권 구분) — 막대 클릭 시 해당 지역 필터 토글
  - 과목별 TO (2027 기본정원·별도정원 누적 표시) — 막대 클릭 시 해당 과목 필터 토글
  - 병원 규모별 분포 (도넛 차트) — 클릭 시 규모 필터
  - 지역 × 과목 히트맵 — 셀 클릭 시 지역·과목 동시 필터
- **병원별 탐색 & 비교**: TO 순위·전반기 대비 증감 → 병원 클릭 시 2022–2027 레지던트/인턴 추이 및 과목별 상세 모달, 최대 4개 병원 나란히 비교
- **연도별 증감·2027 분석**: 임의의 두 시기 비교(지역별·과목별 증감 차트) + 2027 별도정원·감원·신규 지정 요약
- **전체 데이터 표**: 열 정렬, 2027 기본/별도/감원 상세, 필터 결과 **CSV 내려받기**

## 데이터 처리 규칙
- 지역명 정규화: `서울특별시→서울`, `강원도→강원`, `경상남도→경남` 등
- 병원명 정규화: 2022–2026 약칭과 2027 공식 병원명을 표준명으로 통합해 연도별 추이 연결
- 과목 통합: `흉부외과 → 심장혈관흉부외과` (2023 후반기 개칭 반영)
- **병원 규모**: 각 시기 레지던트 총 TO 기준 — 대형 30↑ / 중형 10–29 / 소형 9↓
  (인턴만 운영하는 병원은 인턴 TO로 보정)

## 데이터 갱신
원본 CSV를 추가/수정한 뒤 프로젝트 루트에서:

```bash
python3 build_data.py
```

모든 `*.csv` 를 다시 읽어 `web/data.js` 를 재생성합니다. (macOS 한글 파일명 NFD 자동 처리)

## 구성
```
build_data.py        CSV → web/data.js 변환 스크립트
web/index.html       대시보드 (이 파일을 연다)
web/app.js           로직 + SVG 차트 (의존성 없음)
web/styles.css       스타일
web/data.js          자동 생성 데이터 (직접 수정 금지)
```
